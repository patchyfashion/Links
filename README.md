# PATCHY — باتشي

صفحة روابط متجاوبة لإنستغرام وفيسبوك وواتساب، بتأثيرات خياطة وإبرة وخيط من CSS وSVG.

## تغيير الروابط
عدّل `SOCIAL_LINKS` في `script.js`. تأكد من صحة الروابط قبل النشر.

## تغيير الشعار
النسخة على GitHub تستخدم `assets/logo.svg` الرمادي. لاستخدام PNG، ارفع `assets/logo.png` وغيّر مسار الشعار في `index.html` و`script.js` من `assets/logo.svg` إلى `assets/logo.png`. ملف ZIP المرفق في المحادثة يتضمن PNG جاهزًا.

## GitHub Pages
Settings → Pages → Deploy from a branch → main / (root) → Save.

الصفحة لا تحتاج خادمًا خلفيًا، وتدعم الموبايل و`prefers-reduced-motion`.
